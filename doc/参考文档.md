# 选股指标手册

> 整理自 2026-07-28 对话，持续补充（最后更新：2026-08-05）

---

## 一、选股四维框架（最重要）

买任何股票前，四个维度至少三个绿灯才考虑。

| 维度 | 权重 | 核心问题 | 红灯信号 |
|------|------|----------|----------|
| **趋势面** | 25% | 股价在涨还是在跌？ | 20日均线死叉向下、不断新低 |
| **资金面** | 20% | 主力在进还是出？ | 主力连续净流出、散户接盘 |
| **基本面** | 25% | 公司赚不赚钱、贵不贵？ | 亏损、ROE<8%、增速为负 |
| **事件催化** | 15% | 有没有新故事？ | 老概念、无新催化 |
| **估值吸引力** | 15% | PE/PB匹不匹配增速？ | PE>50但增速<10% |

### 优先级铁律：趋势面 > 资金面 > 基本面

趋势向下时，再好的资金流入也可能是陷阱。趋势面和资金面冲突 → **听趋势面的**。

## 二、基本面四大指标

### 1. ROE（净资产收益率）

**公式**：净利润 ÷ 净资产 × 100%

**含义**：股东投进去的钱，一年能赚多少回报。

| ROE | 评价 |
|-----|------|
| > 20% | 优秀（茅台级别） |
| 15%~20% | 良好 |
| 8%~15% | 及格 |
| < 8% | 偏低 |
| < 0% | 亏钱，没法看 |

### 2. 净利润增速

**公式**：（今年净利润 - 去年净利润）÷ 去年净利润 × 100%

**含义**：公司今年比去年多赚了多少。

| 增速 | 评价 |
|------|------|
| > 30% | 高速成长 |
| 15%~30% | 稳健增长 |
| 5%~15% | 勉强还行 |
| 0%~5% | 停滞 |
| < 0% | 走下坡路 |

### 3. PE（市盈率）

**公式**：股价 ÷ 每股收益 = 总市值 ÷ 净利润

**含义**：花多少钱买一块钱利润。PE=20 意味着 20 年回本。

| PE | 评价 |
|----|------|
| < 15 | 便宜 |
| 15~30 | 合理 |
| 30~50 | 偏贵，需增速>20%支撑 |
| 50~100 | 很贵，需增速>30%支撑 |
| > 100 | 泡沫风险 |

**核心规则**：PE 不能孤立看，要和增速匹配。增速 50% 配 PE 50 合理，增速 5% 配 PE 50 就是陷阱。

### 4. PB（市净率）

**公式**：股价 ÷ 每股净资产

**含义**：花多少钱买一块钱公司净资产。

| PB | 评价 |
|----|------|
| < 1 | 破净，打折卖 |
| 1~3 | 合理 |
| 3~5 | 偏高 |
| > 5 | 很贵 |

**PE 和 PB 的分工**：
- PE 为主：消费、制造、医药（利润稳定）
- PB 为主：银行、保险、地产（重资产）
- PB 无用：科技、互联网（轻资产）

**PB 和 ROE 的关系**：高 ROE 的公司才有资格享受高 PB。ROE=9% 配 PB=24 就是泡沫。

---

### 5. 三种 PE 的区别（静态 / TTM / 动态）

你平时看到的 PE 其实有三种，看错了会得出完全不同的结论。

#### 三种 PE 对照表

| 类型 | 怎么算 | 特点 |
|------|--------|------|
| **静态 PE** | 总市值 ÷ 上年度已披露净利润 | 最确定，但最滞后（用的是去年的数据） |
| **PE(TTM)** | 总市值 ÷ 过去12个月滚动净利润 | 比静态新鲜，是最常用的 PE |
| **动态 PE** | 总市值 ÷ **今年预测**净利润 | 看的是未来，不是过去 |

#### 动态 PE 为什么重要

**举例**：某公司当前市值 1000 亿，去年赚了 20 亿，PE(TTM) = 50 倍，看着很贵。但如果机构预测今年赚 50 亿，动态 PE = 1000÷50 = **20 倍**——突然就不贵了。

高增长公司用 TTM 看着贵，动态 PE 会把估值拉下来。**TTM 告诉你"过去贵不贵"，动态 PE 告诉你"按未来算贵不贵"。**

#### ⚠️ 动态 PE 最大的陷阱：拿 Q1 × 4

很多软件的动态 PE 是用**一季报利润乘以 4** 简单年化算出来的。这个方法有一个致命假设：**四个季度赚得一样多**——但很多公司不是。

**真实案例：华电辽能（600396）**

| 数据 | 金额 |
|------|------|
| 系统显示动态 PE | **41 倍**（看着合理） |
| 系统显示 PE(TTM) | 637 倍（看着离谱） |
| 怎么算出 41 倍的？ | 拿 Q1 利润 1.58 亿 × 4 = 全年 6.3 亿 → 258亿÷6.3亿 = 41 |
| 实际靠不靠谱？ | **完全不靠谱** |

华电辽能 2025 年的实际季节性利润分布：

| 季度 | 净利润 |
|------|--------|
| 2025 Q1 | +1.46 亿 ✅ |
| 2025 Q2 | -0.60 亿 ❌ |
| 2025 Q3 | -0.83 亿 ❌ |
| 2025 Q4 | -0.83 亿 ❌ |
| **全年** | **0.28 亿** |

**Q1 赚了 1.46 亿，后面三个季度亏了 1.18 亿，全年只剩 2800 万。** 如果 2026 年还是这个规律，全年净利润约 0.4 亿，对应真实 PE = 645 倍——动态 PE 41 倍是个幻觉。

#### 不同情景下动态 PE 的可信度

| 情况 | TTM PE | 动态 PE | 实际 |
|------|--------|---------|------|
| 增长符合预期 | 50 倍 | 25 倍 | 动态靠谱 ✅ |
| 增长不及预期 | 50 倍 | 25 倍 | 动态骗人 ❌ |
| 公司暴雷 | 50 倍 | 25 倍 | 动态彻底失效 ❌❌ |
| 季节性亏损公司 | 637 倍 | 41 倍 | Q1×4 是哈哈镜 ❌❌❌ |

#### 实操中的正确顺序

1. 先看 **PE(TTM)** → 快速判断估值区间
2. 再看 **净利润增速** → 判断增长能否支撑这个 PE
3. 最后看 **动态 PE** → 如果增速很高，动态 PE 会把估值拉下来，这时候 TTM 贵不算真贵
4. **验证动态 PE 的算法** → 如果是 Q1×4 简单年化，要看公司利润是否有季节性

#### 一句话记

> **TTM 是后视镜，动态 PE 是望远镜。但望远镜的镜片可能是哈哈镜——先确认预测方法靠谱，再相信动态 PE 的数字。**

> 等中报/年报出来后用实际利润验证：如果 Q2 又开始亏损，动态 PE 的幻觉当场破灭。

### ⭐ PE/PB 的板块差异（重要！）

同样的 PE=30，在银行算天价，在半导体算便宜。**PE/PB 不能跨板块比较**，必须按行业对号入座。

#### PE 板块参考区间

| 板块 | 典型 PE | 为什么 |
|------|---------|--------|
| **银行** | 5~10 倍 | 利润稳定但增速低，高杠杆有坏账风险 |
| **地产/建筑** | 5~15 倍 | 周期性强，增长空间有限 |
| **钢铁/煤炭** | 5~15 倍 | 强周期，利润波动大，PE 低时往往是顶部 |
| **保险** | 10~20 倍 | 利润随市场波动，比银行略高 |
| **家电/白电** | 10~20 倍 | 成熟行业，增速稳定 |
| **水泥/建材** | 10~20 倍 | 周期+基建，稳定偏低 |
| **通用设备/制造业** | 15~30 倍 | 有一定成长性，利润稳定 |
| **白酒/食品消费** | 20~40 倍 | 品牌护城河、稳定增长，市场愿意给溢价 |
| **医药/医疗器械** | 25~50 倍 | 高研发壁垒，刚需+老龄化逻辑 |
| **新能源（光伏/锂电）** | 20~50 倍 | 高增长但竞争激烈，估值波动大 |
| **半导体/芯片** | 30~80 倍 | 国产替代+高成长预期，行业整体偏贵 |
| **AI/云计算** | 30~100 倍 | 爆发式增长，市场给极高预期 |
| **军工** | 30~60 倍 | 壁垒高但利润不透明，情绪驱动为主 |
| **游戏/传媒** | 15~30 倍 | 项目制不确定，偶尔出爆款 |

#### PB 板块参考区间

| 板块 | 典型 PB | 为什么 |
|------|---------|--------|
| **银行** | 0.5~1.2 倍 | 资产庞大但收益率低，破净是常态 |
| **钢铁/煤炭** | 0.8~2.0 倍 | 重资产行业，设备折旧拖累 |
| **地产** | 0.5~1.5 倍 | 土储虽值钱但变现能力存疑 |
| **制造业** | 1.5~4.0 倍 | 中等资产密度，ROE支撑PB |
| **白酒消费** | 4.0~12.0 倍 | 轻资产+强品牌，溢价极高 |
| **医药** | 3.0~8.0 倍 | 研发管线是隐形资产，账面PB低估真实价值 |
| **半导体** | 3.0~10.0 倍 | 高成长预期，设备/技术值钱 |
| **科技/互联网** | PB 基本不适用 | 轻资产，核心资产是人+数据，不在账面上 |

#### 实战速查表

| 场景 | PE | PB | 判断 |
|------|-----|-----|------|
| 银行 PE=30 | 🔴 太贵 | — | 银行 PE 几乎不可能到 30 |
| 银行 PE=6 + PB=0.7 | 🟢 合理 | 🟢 | 破净但行业常态 |
| 白酒 PE=30 | 🟢 合理 | — | 消费品里算便宜 |
| 半导体 PE=80 | 🟡 偏贵 | — | 但有国产替代逻辑支撑 |
| 钢铁 PE=8 | ⚠️ 不是便宜 | — | 周期性顶部 PE 最低反而最危险 |
| 制造业 PE=25 + PB=3 | 🟢 合理 | 🟢 | 中等估值匹配中等增长 |

**一句话**：用 PE 选股时先问自己——"这只票在什么行业？这个行业的正常 PE 区间是多少？"

## 三、资金面三大判断标准

### 1. 主力净额占成交额比例

| 占比 | 含义 |
|------|------|
| > 5% | 主力大举抢筹 |
| 2%~5% | 明显流入 |
| -2%~2% | 观望 |
| -5%~-2% | 明显流出 |
| < -5% | 主力撤退 |

### 2. 连续性和趋势

- 连续 3 天同向 → 可信
- 一天进一天出 → 震荡，信号无效
- 流入量递减（如 +5亿 → +3亿 → +1亿）→ 力量衰竭，危险

### 3. 超大单 vs 大单

| 超大单 | 大单 | 含义 |
|--------|------|------|
| 正 | 正 | 共识做多，最理想 |
| 正 | 负 | 机构买、游资卖 |
| 负 | 正 | 机构卖、游资接，危险 |
| 负 | 负 | 共识出逃，最危险 |

## 三补充、趋势面核心指标

### 1. 20日均线（MA20）

**含义**：过去20个交易日收盘价的平均值连成的线。是判断短期趋势最重要的单一指标。

**用法**：
- 股价在20日线上方 + 均线向上 → 上升趋势，可以关注
- 股价在20日线下方 + 均线向下 → 下跌趋势，远离
- 股价从上方回踩20日线企稳 → 回调买点
- 股价从下方突破20日线 → 反转信号（需放量确认）

**和资金面的优先级**：趋势面 > 资金面。20日线向下时，资金流入也可能是陷阱。

### 2. MACD 金叉与死叉

**含义**：MACD 是判断趋势转折的经典指标。

| 信号 | 形态 | 含义 |
|------|------|------|
| **金叉** | MACD线（快线）从下方上穿信号线（慢线） | 🟢 买入信号，趋势可能转多 |
| **死叉** | MACD线从上方下穿信号线 | 🔴 卖出信号，趋势可能转空 |

**注意**：金叉/死叉不能单独用，必须结合量能和均线。金叉不放量 = 假金叉；死叉 + 放量跌 = 加速出逃。

## 四、行情基础指标

### 1. 量比

**公式**：今天开盘到现在的成交量 ÷ 过去5天同一时段的平均成交量

**含义**：衡量今天成交量"不正常程度"。不是全天对比，而是同一时段对比，所以盘中会一直变。

| 量比 | 含义 |
|------|------|
| 0.8~1.2 | 正常水平 |
| > 1.5 | 明显放量，有人在搞事情 |
| > 2.5 | 显著放量，大动作 |
| > 5 | 极端放量，抢筹或恐慌抛售 |
| < 0.5 | 极度缩量，常见于跌停封死 |

**量比 × 涨跌 组合判断**：

| 量比 | 涨跌 | 含义 |
|------|------|------|
| > 1.5 | 涨 | 🔥 放量上涨，真金白银在推 |
| > 1.5 | 跌 | 🔴 放量下跌，恐慌或主力砸盘 |
| < 0.8 | 涨 | ⚠️ 无量拉升，诱多嫌疑 |
| < 0.8 | 跌 | ⚠️ 缩量阴跌；若跌停则是封死卖不掉 |

### 2. 换手率

**公式**：当日成交量 ÷ 流通股本 × 100%

**含义**：今天有多少比例的股票换了主人。衡量筹码交换的活跃度。

| 换手率 | 含义 |
|--------|------|
| < 1% | 冷门，无人关注 |
| 1%~3% | 正常 |
| 3%~7% | 活跃，有资金关注 |
| 7%~15% | 非常活跃，多空博弈激烈 |
| > 15% | 异常，筹码快速换手——可能是主力对倒或出货 |

**量比 vs 换手率 的区别**：量比是跟自己过去比（今天热不热），换手率是绝对换手量（筹码换了多少）。两个一起看，一只票量比2+换手率5%，说明"比平时热闹得多、筹码大量交换"。

### 3. 委比

**公式**：（委买手数 - 委卖手数）÷（委买手数 + 委卖手数）× 100%

**含义**：当前挂单的买卖力量对比。正值 = 买盘多，负值 = 卖盘多。

| 委比 | 含义 |
|------|------|
| > 50% | 买盘碾压，可能涨停 |
| 0%~50% | 买盘略多 |
| -50%~0% | 卖盘略多 |
| **-100%** | 🔴 全是卖盘，常见于跌停封死 |

### 4. 成交额与成交量

| 指标 | 含义 |
|------|------|
| **成交量** | 今天成交了多少股（单位：手） |
| **成交额** | 今天成交了多少钱（单位：元） |

成交额 = 成交量 × 均价，比成交量更能反映真实资金规模。一只高价股100万股和一只低价股100万股，成交额可能差10倍。

### 5. 总市值与流通市值

| 指标 | 含义 |
|------|------|
| **总市值** | 股价 × 总股本，整家公司值多少钱 |
| **流通市值** | 股价 × 可自由交易的股本，市场上实际流通的钱 |

小市值( < 50亿)容易被游资操控，大市值( > 1000亿)走势更稳但涨得慢。

## 五、辅助财务指标

### 1. 毛利率

**公式**：（营业收入 - 营业成本）÷ 营业收入 × 100%

**含义**：产品卖出去后，扣除直接成本还剩多少。越高说明产品越有定价权。

| 毛利率 | 评价 |
|--------|------|
| > 60% | 暴利（茅台、软件） |
| 30%~60% | 不错 |
| 15%~30% | 普通制造业水平 |
| < 15% | 辛苦钱，薄利多销 |

### 2. 净利率

**公式**：净利润 ÷ 营业收入 × 100%

**含义**：每卖出100块钱的货，最终落到口袋里的利润。比毛利率更"真实"，因为扣了管理费、利息、税费等所有开支。

毛利率高但净利率低 → 说明费用吃掉了利润，生意模式不够好。

### 3. 资产负债率

**公式**：总负债 ÷ 总资产 × 100%

**含义**：公司有多少钱是借来的。杠杆水平。

| 负债率 | 评价 |
|--------|------|
| < 30% | 保守，财务安全 |
| 30%~50% | 正常 |
| 50%~70% | 偏高，关注偿债压力 |
| > 70% | 🔴 高杠杆，风险大（银行除外） |

### 4. 营收增速 vs 净利润增速

**增收又增利**（营收增速↑ + 净利增速↑）→ 最健康
**增收不增利**（营收增速↑ + 净利增速↓）→ 在降价抢市场或成本上升，需警惕
**不增收但增利**（营收增速↓ + 净利增速↑）→ 可能在收缩规模提效，不可持续

## 六、量价关系口诀

| 组合 | 方向 | 含义 |
|------|------|------|
| 放量涨 | ✅ 看多 | 钱在进场推动股价 |
| 缩量跌 | ✅ 看多 | 抛盘衰竭，卖的人越来越少 |
| 放量跌 | ❌ 看空 | 恐慌出逃或主力砸盘 |
| 缩量涨 | ❌ 看空 | 无量拉升，诱多 |

**⚠️ 跌停板上的缩量不算缩量跌**——是流动性枯竭，想卖的排队卖不掉。

## 七、三种下跌类型

| 场景 | 特征 | 能买吗 |
|------|------|--------|
| **上升趋势正常回调** | 20日线向上，缩量回踩、主力没跑 | ✅ 可以 |
| **底部筑底后反转** | 长期横盘后放量突破均线、MACD金叉 | ⚠️ 可以但不适合新手 |
| **单边下跌途中** | 均线死叉向下、不断新低、主力流出 | ❌ 绝对不能 |

## 八、买入前 5 个问题（任何一只都问一遍）

1. 趋势对吗？（20日均线方向？价格在均线上方吗？）
2. 钱在进还是出？（近3-5天主力净流入？流入量在递增还是衰减？）
3. 基本面撑得住吗？（ROE>8%？增速正？PE匹配增速？）
4. 我买的理由是什么？（信号触发，还是情绪驱动？）
5. 亏多少我走？（止损线设好了没？）

**有一项不满足就不买。**

## 九、漏斗筛选法（日常操作）

```
5000+ 只全市场
  ↓ ROE>8%、净利不亏损 → 剩 ~800 只
  ↓ 20日线向上、非ST → 剩 ~200 只
  ↓ 近5日主力净流入为正 → 剩 ~30-50 只
  ↓ PE/增速匹配 + 有新催化 → 关注池 5-10 只
```

日常工作量：每天 5 分钟扫资金，每周 10 分钟看趋势，每季度 30 分钟更新财报。95% 时间在等，5% 时间在买。

## 十、冰轮环境教训（真实案例速查）

| 维度 | 你买入时(42.76) | 结论 |
|------|----------------|------|
| 趋势 | 20日线死叉向下，58→43 一路跌 | ❌ |
| 资金 | 连续5天正，但流入量在衰减 | ⚠️ 诱多信号 |
| 基本面 | ROE 9%、增速-10%、PE 66 | ❌ 不匹配 |
| 估值 | PB 23.7 vs ROE 9% | ❌ 泡沫 |

**教训**：趋势向下时，资金流入可能是反弹尾声的陷阱。四个维度全红就不该买。

## 十一、A股交易基础规则

### 1. 交易时间

| 时段 | 时间 | 能做什么 |

| 连续竞价（早盘） | 9:30~11:30 | 正常交易 |
| 连续竞价（午盘） | 13:00~15:00 | 正常交易 |

| 夜市委托 | 当日收盘后~次日 9:15 | 部分券商支持，挂的单明天集合竞价才生效 |

### 2. 代码规则

| 开头 | 交易所 | 板块 | 涨跌幅限制 |
|------|--------|------|-----------|
| 60xxxx | 上海主板 | 沪市 | ±10% |
| 00xxxx | 深圳主板 | 深市 | ±10% |

ST/*ST（风险警示股）涨跌幅统一为 ±5%（创业板/科创板 ST 仍为 ±20%）。

### 3. 核心交易制度

| 规则 | 说明 |
|------|------|
| **T+1** | 今天买的，**明天才能卖**。卖出的钱当天可用（买别的），但提现需 T+1 |
| **100 股起买** | 最少买 100 股（1 手），之后必须是 100 的整数倍 |
| **涨跌停板** | 达到涨跌停价格后，仍然可以挂单排队，但不一定能成交 |
| **价格优先 + 时间优先** | 买单：谁出价高谁先成交；同价时谁先挂谁先成交 |

### 4. 费用

| 费用 | 比例 | 谁收 |
|------|------|------|
| 佣金 | 约万分之 2.5（最低 5 元） | 券商 |
| 印花税 | 卖出时收万分之 5 | 国家 |
| 过户费 | 万分之 0.1 | 中国结算 |

买 1000 块钱的股票大概花 5.1 元手续费，卖出再花 5.6 元——**买卖一次约 1% 的成本**。所以频繁交易等于给券商和国家打工。

## 十二、K线基础

### 什么是 K 线？

一根 K 线 = 一段时间内四个价格的图形化记录。

```
        ← 最高价
        │
   ┌────┐
   │    │ ← 实体（开盘/收盘之间的部分）
   │    │   红=涨(收盘>开盘)，绿=跌(收盘<开盘)
   └────┘
        │
        ← 最低价
```

| 形态 | 含义 |
|------|------|
| **大阳线**（实体长、光头光脚） | 强烈看涨，买方碾压 |
| **大阴线**（实体长、光头光脚） | 强烈看跌，卖方碾压 |
| **十字星**（实体极小、上下影线长） | 多空平衡，方向不明，可能是变盘信号 |
| **锤头线**（下方影线极长、小实体在上方） | 探底回升，下跌末端出现可能是反转 |
| **倒锤头**（上方影线极长、小实体在下方） | 冲高回落，上涨末端出现可能是反转 |
| **一字板**（无实体、无影线） | 涨跌停封死，无成交 |

### K线周期

| 周期 | 用途 |
|------|------|
| 日K线 | 最常用，看短期趋势 |
| 周K线 | 看中期趋势（一周一根） |
| 月K线 | 看长期大趋势 |
| 60分钟/30分钟 | 超短线看盘口 |

**新手只看日K线和周K线就够了**——分钟级别的太短，容易被噪音干扰。

## 十四、交易心态与纪律

### 最重要的一条铁律

> **止损不止损，决定了你在这个市场是活着还是被抬走。**

亏 5% 你只需要涨 5.3% 就能回本。亏 20% 你需要涨 25% 才能回本。亏 50% 你需要涨 100% 才能回本。

### 仓位管理三原则

| 原则 | 说明 |
|------|------|
| **永不单吊一只** | 全仓一只票，一旦踩雷就全没。至少分 3 只以上 |
| **单只上限 30%** | 单只股票占总资金不超过 30%，避免一颗炸弹炸全家 |
| **永远留现金** | 任何时候至少留 20% 现金，用来应对暴跌和捡漏 |

### 新手必守五条纪律

| # | 纪律 | 为什么 |
|------|------|--------|
| 1 | **先模拟，后真钱** | 用真钱之前，先用模拟盘验证你的策略至少 3 个月 |
| 2 | **不追涨停板** | 你追进去的时候，往往就是主力出货给你的时候 |
| 3 | **不抄下跌的底** | 趋势向下的时候，"底"下面还有"地下室"。等止跌确认再说 |
| 4 | **设止损线并执行** | 买入时就写好"亏多少我走"，到了就走，不要幻想 |
| 5 | **日亏损 > 5% 当天停手** | 亏红眼了继续操作，只会亏更多。停一天冷静 |

### 最常见的亏钱心态

| 心态 | 表现 | 后果 |
|------|------|------|
| **侥幸** | "再等等就回来了" | 从微亏变成深套 |
| **贪婪** | "还能再涨，不卖" | 盈利变亏损 |
| **恐惧** | "跌了好多，赶紧割" | 卖在最低点 |
| **报复** | "上次亏了，这次要赚回来" | 加倍下注，加倍亏 |
| **从众** | "别人都买了，我也买" | 买在最高点 |

### 一句话总结心态

**亏钱不可怕，可怕的是亏了不知道为什么会亏。每一次亏损都是一堂课，只要你愿意复盘，学费就没白交。**

## 十五、新手常见陷阱

### 🔴 陷阱一：荐股群 / "老师"带单

拉你进群，每天推荐"暴涨股"，前几只看对了，等你信任了，最后一只让你重仓买入——然后他们出货跑路，你在山顶站岗。**原理**：他们先买好，推荐给你抬轿子。

**识别特征**：高收益承诺、截图晒单、"内部消息"、"即将拉升"、"跟上吃大肉"。

### 🔴 陷阱二：杀猪盘

比荐股群更狠，通过社交软件发展"感情"，取得信任后引导你买入某只股票——你买进去就是最高点，对方直接跑路。

**识别特征**：陌生人主动加你、聊感情、慢慢引导"投资"、指定买某只股票。

### 🔴 陷阱三：涨停板战法陷阱

"今天抓涨停，明天高开卖"——等你挂涨停价排进去，主力已经开始跑了。涨停板上你是最后一个知道的，永远是接盘侠。

### 🔴 陷阱四：ST股赌重组

买入已经 ST/*ST 的股票，赌它"摘帽"或"重组"暴赚。但在 A 股，ST 退市的概率远大于暴富概率。一旦退市，账户里的数字可能真的归零。

### 🔴 陷阱五：追热门概念 / 追新闻

看到新闻"XX板块迎来重大利好"就冲进去——等新闻上头条的时候，知道的人早就进去了，你是最后一批。

**经验**：如果连你一个普通人都看到了这则"利好"，这个利好至少已经被市场消化了 48 小时。

### 🔴 陷阱六：下跌途中不断补仓

买了之后跌了 5%，补一倍摊低成本。再跌 5%，再补。最后发现子弹打光了，股票还在跌——这就是"越跌越买，越买越套"。

**正确做法**：买入时设好止损线，跌破了就走。别把"补仓"当策略，它是一种赌博。
